# Semesterplaner

Stundenplan, Lernplanung und Fortschritt für ein 14-wöchiges Bauingenieur-Semester (HS 2026).

**Seite:** https://silvankummer2-beep.github.io/semesterplaner/

- **Lernplan** – Aufwand je Fach, Lernblöcke pro Tag, Status je Fach und Woche
  (offen, in Arbeit, abgeschlossen, nichts zu tun, nicht gemacht)
- **Stundenplan** – Wochenraster mit Turnus A/B (Baustatik/Massivbau am Montag,
  Verkehrswesen/Stahlbau am Donnerstag)
- **Prüfungen & Abgaben** – Termine mit Art, Fach und Datum; erscheinen in der passenden Woche
- **Semester** – 14-Wochen-Raster über alle Fächer

Die Daten liegen im Browser (localStorage) und können optional über einen privaten
GitHub-Gist zwischen Geräten abgeglichen werden (Tab „Fächer & Zeit" → Daten & Sicherung).
Es gibt keinen Server: nichts wird an Dritte gesendet.
